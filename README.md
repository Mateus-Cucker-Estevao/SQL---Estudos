## 📌 Conteúdos já estudados

- **CTE (Common Table Expression)** — `WITH ... AS (...)`
- **Variáveis** — `DECLARE`, `SET`
- **Concatenação** — `+`, `CONCAT()`
- **Funções de texto** — `LEN`, `LTRIM`, `RTRIM`, `TRIM`, `UPPER`, `LOWER`
- **Extração de string** — `SUBSTRING`, `LEFT`, `RIGHT`, `CHARINDEX`
- **Substituição** — `REPLACE`
